# Linux & Network Security Investigation Toolkit

A beginner cybersecurity project built with Python, Linux, and TShark.

## Features
- Collect basic system and network information
- Inspect file permissions
- Analyze PCAP/PCAPNG packet captures
- Filter UDP traffic using port 53
- Generate protocol statistics reports

## Requirements
- Python 3
- TShark
- Ubuntu or Ubuntu on WSL

## Run
```bash
python3 security_toolkit.py
